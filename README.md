## Executive Summary

Modern webmasters, founders, marketers, and autonomous AI agents face severe friction with traditional SEO tooling:
1. **Predatory Recurring Subscriptions:** Legacy platforms demand **$99–$249 every month** on recurring credit cards, even if a user only audits a single landing page or a couple of client releases.
2. **Missing AI Search Optimization (AEO & GEO):** Traditional SEO checkers ignore conversational search tools. Websites lose citations and traffic to Perplexity, ChatGPT, Claude, and Google AI Overviews because they lack `/llms.txt`, direct answer readiness, and verified crawler permissions in `robots.txt`.
3. **No Machine Payment Rails for AI Agents:** Autonomous software agents cannot swipe credit cards or solve CAPTCHAs.
4. **Metric Fabrication:** Most tools guess global search volume or third-party difficulty scores rather than inspecting real on-page code and visible content.

**CrawlPay** is an autonomous economic agent that replaces rigid monthly subscriptions with **on-demand, pay-per-crawl audits** settled over **HTTP 402 (x402)** via `@celo/buy` on **Celo Mainnet**.

## Core Capabilities (SEO, AEO & GEO)

### 1. The 3 Optimization Pillars
* **SEO (Search Engines — Google & Bing):** Canonical tags, heading hierarchy (H1–H3), Core Web Vitals (LCP, CLS, FID), redirect chains, meta robots, XML sitemaps, and broken link detection up to 50 pages.
* **AEO (Answer Engine Optimization — Direct Answers):** Question headings, concise answer definitions, and conversational Schema.org FAQ/Article JSON-LD for instant extraction by conversational answer engines.
* **GEO (Generative Engine Optimization — AI Assistants):** AI bot permissions in `robots.txt` (`GPTBot`, `ClaudeBot`, `PerplexityBot`), `/llms.txt` context compliance, brand entity knowledge graph links, and server-rendered HTML readiness.

### 2. On-Page Keyword & Question Intelligence
* Extracts keyword pairs, customer questions, and comparison angles directly from visible page text.
* Zero fabricated metrics: never invents estimated search volumes or third-party keyword difficulties.

### 3. Google Search Console (GSC) Upload & Cross-Reference
* Upload GSC exports (`.csv`, `.tsv`, or `.zip` archives directly unzipped via browser memory).
* Cross-references Google's unindexed URLs and coverage status types (`Crawled - currently not indexed`, `Duplicate without canonical`) with CrawlPay's on-page technical fixes.

### 4. Stack-Tailored Copy-Paste Code Fixes
* Automatically detects the target CMS / framework (**Next.js App Router**, **WordPress**, **Shopify**, **Astro**, **HTML5**).
* Produces paste-ready code patches and valid Schema.org JSON-LD tags.

### 5. Side-by-Side Competitor Benchmarking
* Compares your site against any rival domain on speed vitals, schema count, and AI crawler permissions, generating a clear 3-step outranking action plan.

### 6. Client-Ready Print / PDF Reports
* Dedicated print stylesheet (`@media print`) that forces high-contrast light mode, smart page-break avoidance, unclipped code snippets, and an official audit report header for agencies and clients.

## Claude & MCP Integration

CrawlPay includes a native **Model Context Protocol (MCP)** server so AI assistants like Claude Desktop can audit live websites directly inside chat:

### Configuration (`claude_desktop_config.json`)
```json
{
  "mcpServers": {
    "crawlpay": {
      "command": "npx",
      "args": ["tsx", "scripts/mcp-server.ts"],
      "cwd": "/path/to/crawlpay"
    }
  }
}
```

### Available MCP Tools
* `crawlpay_audit_site`: Run a deterministic technical SEO, AEO & GEO audit on any public website.
* `crawlpay_compare_competitor`: Benchmark your site against a direct competitor.
* `crawlpay_agent_status`: Retrieve live Celo Mainnet telemetry, wallet balances, and ERC-8004 agent registration.
* `handle_payment_required`: Automatically handle HTTP 402 challenges by executing $0.50 USD₮ micropayments with ERC-8021 attribution.

```bash

```
